# AstrBot E2B 云沙箱插件 (`astrbot_plugin_e2b_sandbox`)

![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20Docker-blue)
![Version](https://img.shields.io/badge/Version-1.6.0-blueviolet)

让你的 AstrBot 拥有专属的云端 Python 电脑：发一句话或丢个文件，机器人就能在隔离的云沙箱里算数据、一次绘制多张中文图表、处理表格并把结果发回给你，不占本机资源、也不暴露宿主机权限。

---

## 🎯 它能做什么 & 为什么选它

在日常对话中直接提需求或分条发送附件（完美支持 QQ / 微信“先发文档、下一条再发文字指令”），机器人会自动编写并运行 Python 代码：

- 📊 **读表与多图绘制**：发 Excel / CSV 让它画趋势图、占比图，按需自动配置中文字体并批量回传多张高清图片，告别方块乱码。
- 🧮 **数据清洗与导出**：筛选、汇总上万行表格（含子目录输出文件自动捕获），把生成的新 Excel / 文件直接发回聊天。
- 🌐 **联网抓取与分析**：在云端直接访问公开网页抓取内容、提取并总结要点。
- 🐍 **复杂运算与逻辑验证**：数学建模、批量文本处理、脚本验证，非绘图任务零额外启动负担，秒级响应。

**核心优势：**

- 💻 **小配置机器也能干重活**：计算与绘图全在 E2B 云端运行，预装库毫秒级智能跳过重复安装，1 核 1G 轻量服务器也不卡顿。
- 🛡️ **云端与宿主机双向安全隔离**：代码跑在云沙箱不触碰你的服务器，宿主机侧内置 **SSRF 私网/云元数据拦截** 与 **本机敏感路径防护**，普通用户无需 AstrBot 管理员权限即可安全使用。
- 👥 **灵活的群聊隔离策略**：既支持全群共用一台协作沙箱（`session`），也支持开启**群成员独立沙箱（`group_member`）**防串文件、防误删。
- 🔑 **多 Key 并行轮询与账号备注**：支持配置多把 E2B API Key 并附加可读备注（如 `e2b_xxx # 主力号`），不同账户独立并发创建不互卡，单 Key 限流或欠费自动冷却切换。
- 🖥️ **全新可视化 WebUI 控制台**：直观展示四步省钱生命周期流转、并发槽位矩阵、渠道与群/私聊可读身份、休眠剩余寿命进度条、传入/产出文件胶囊，支持**表格 / 云机卡片双视图**与一键核对安全管控。

## 📌 使用前必读

动手配置前，请先确认以下 3 条关键规则（避坑必看）：

1. **无需开启 AstrBot 全局 `sandbox`**：在 AstrBot 管理面板 **「设置 → 普通配置 → 使用电脑能力 → 运行环境」** 中，保持 `local` 或 `none` 即可——AstrBot 自带沙箱与本插件不是同一套机制。仍需本机能力选 `local` 并保持“本机执行需要管理员”开启；只用云端沙箱选 `none` 即可。
2. **确认人格已启用插件工具**：如果你给当前人格手动勾选过可用工具，请记得勾选本插件的 `e2b_sandbox_*` 工具（或选全部）。插件加载成功不代表人格允许调用。
3. **注意群聊隔离模式选择（`sandbox_scope`）**：
   - 默认 `session`（群聊共用）：同一群聊所有成员共用一台云沙箱，适合多人接力协作，但**群友之间无数据隔离，切勿在共用模式下处理个人私密文件**。
   - 可选 `group_member`（群成员独立）：在配置中切换为 `group_member` 后，群内每位成员各自拥有独立云沙箱，互不串文件、互不阻塞。

## 🛠️ 快速开始

> 环境要求：**AstrBot >= 4.9.2**，**Python >= 3.10**。

### 1. 安装插件与依赖

在 AstrBot 管理面板插件市场中安装，或直接填入本仓库地址安装：

```text
https://github.com/sl251/astrbot_plugin_e2b_sandbox
```

如宿主环境未自动安装依赖，请在运行 AstrBot 的 Python 环境中执行：

```bash
pip install 'e2b-code-interpreter>=2.3.0,<3.0.0'
```

### 2. 获取 E2B API Key

前往 [E2B 官网控制台](https://e2b.dev/) 注册账号并创建 API Key。新用户注册赠送一次性 **$100 免费额度**（详情见下方「计费与额度参考」）。

### 3. 填写核心配置

进入 AstrBot 管理面板 **「插件 → `astrbot_plugin_e2b_sandbox` → 配置」**，新手只需关注以下 3 项（其余保持默认即可）：

- **API Key（`e2b_api_keys`）**：每行填入一个 Key（支持 `e2b_xxx # 主力号` 语法为管理面板添加备注名）；只有一把 Key 也填这里即可。
  - *如果是从 v1.3.x 及更早版本升级且保留了旧会话，请先看下方「从旧版单 Key 升级指南」。*
- **网络代理（`proxy`）**：E2B 服务位于海外，**国内服务器必须填写代理地址**（例如 `http://127.0.0.1:10809`），海外服务器留空。
- **用户白名单（⚠️ 必看）**：插件默认开启白名单（`enable_user_whitelist = true`）且名单为空，**不修改则所有人都会被拒绝**：
  - 允许所有人使用 → 将 `enable_user_whitelist` 设为 `false`。
  - 只允许特定人使用 → 保持开启，并在 `user_whitelist` 填入用户 ID（如 QQ 号）。

### 4. 重载并测试

保存配置并重载插件，在聊天中新建对话发送：

> “用 Python 帮我算一下 1 到 100 的累加和，并解释过程”

机器人调用云端沙箱并返回 `5050`，即说明配置成功。

## ⏳ 沙箱生命周期与运行规则

你可以把“沙箱”理解为云端为每个聊天会话（或群成员）分配的一台“临时云电脑”：同一作用域内的变量和文件会在多轮对话间保留，并遵循自动省钱规则：

- **执行完默认自动休眠**：每次代码跑完后自动暂停；若处于运行状态且连续无任务超过 `idle_pause_seconds`（默认 30 秒），也会在后台自动暂停。**暂停后不计费、不占用同时运行名额**，且沙箱内的文件与变量完整保留。
- **休眠超时会自动销毁**：沙箱暂停超过 `paused_sandbox_retention_hours`（默认 12 小时）会被后台彻底销毁。**销毁后沙箱内的文件与变量永久丢失且无法恢复**（普通聊天不会延长暂停保留时间），重要结果请及时让机器人发回保存。
- **全局并发与排队**：插件实例默认最多同时运行 `max_running_sandboxes`（3 台）沙箱；名额满时最多让 `max_queue_size`（10 个）请求排队，最长等待 `queue_wait_timeout`（15 秒），超时返回繁忙提示。
- **跨消息附件与缓存保护**：支持在 QQ / 微信中先单独发送文档（或群文件上传），随后在 30 分钟内发文字指令自动带入沙箱（已上传过的文件后续轮次不会重复上传）。单个附件上传上限默认为 `max_upload_file_size_mb`（20 MB，仅允许公网 HTTP/HTTPS 链接与受保护的临时附件缓存），回传单个文件上限默认为 `max_return_file_size_mb`（5 MB）。本地导出缓存在 `data/plugin_data/astrbot_plugin_e2b_sandbox/exports/`，默认保留 `file_retention_hours`（24 小时）。

## ⚙️ 配置项说明

### 1. 基础连接与密钥

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `e2b_api_keys` | 字符串列表 | 空 | **主入口**：每行一个 E2B API Key（支持 `e2b_xxx # 主力号` 添加面板备注）；新沙箱轮询，旧沙箱绑定原 Key |
| `e2b_api_key` | 字符串 | 空 | **升级迁移用**：仅用于识别升级前创建的旧沙箱归属；新安装留空即可 |
| `proxy` | 字符串 | 空 | E2B 请求与公网附件下载代理地址，国内服务器示例：`http://127.0.0.1:10809` |
| `default_template` | 字符串 | 空 | 默认 E2B 模板 ID，留空使用官方默认环境 |

### 2. 权限、群聊隔离与执行路由

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `sandbox_scope` | 字符串 | `session` | 群聊隔离粒度：`session`（全群共用协作）或 `group_member`（群聊按成员独立沙箱，私聊不受影响） |
| `enable_user_whitelist` | 布尔值 | `true` | 是否开启用户白名单；开启且名单为空时禁止所有人，关闭则对所有人开放 |
| `user_whitelist` | 字符串列表 | 空 | 允许使用的用户 ID（例如 QQ 号），仅在白名单开启时生效 |
| `prefer_e2b_for_code` | 布尔值 | `true` | 开启后，日常计算、绘图、附件处理优先提示走云端沙箱；明确针对宿主机的任务仍按原权限处理 |
| `hide_restricted_local_tools` | 布尔值 | `true` | 会话为 `local` 且要求管理员时，为通过插件准入的非管理员隐藏本机命令执行工具（保留文件工具） |

### 3. 运行、并发与生命周期

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `timeout` | 整数 | `60` | 单次 Python 代码执行超时（秒，最小 `5`） |
| `max_output_length` | 整数 | `2000` | 返回给模型的执行结果文本上限（字符，范围 `200–20000`） |
| `max_running_sandboxes` | 整数 | `3` | 当前插件实例全局同时运行沙箱上限（范围 `1–20`；暂停沙箱不占名额） |
| `max_queue_size` | 整数 | `10` | 名额满时最大排队请求数（范围 `0–100`；`0` 表示不排队直接返回繁忙） |
| `queue_wait_timeout` | 整数 | `15` | 排队等待名额的最长秒数（范围 `1–120`） |
| `allow_keep_running` | 布尔值 | `false` | 开启后才允许模型在执行后保持沙箱运行（`auto_pause=false`）；空闲暂停仍生效 |
| `idle_pause_seconds` | 整数 | `30` | 沙箱无任务空闲多久后自动暂停（秒，范围 `5–3600`） |
| `paused_sandbox_retention_hours` | 整数 | `12` | 暂停沙箱保留时长（小时，范围 `1–720`）；到期彻底销毁，变量与文件无法恢复 |

### 4. 文件传输与缓存

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `max_upload_file_size_mb` | 整数 | `20` | 单个附件上传上限（MB，范围 `1–100`），同时限制公网 HTTP(S) 下载与本地附件读取 |
| `max_return_file_size_mb` | 整数 | `5` | 允许下载并发送给用户的单个结果文件上限（MB，范围 `1–50`） |
| `file_retention_hours` | 整数 | `24` | 本地 `exports/` 目录导出缓存文件的保留时长（小时，范围 `1–168`） |

## 🖥️ 可视化控制台与多 Key 并行轮询

### WebUI 可视化控制台

入口：**AstrBot WebUI → 插件 → `astrbot_plugin_e2b_sandbox` → `dashboard`**

- **直观可读展示**：
  - **四步生命周期流转条 & 并发槽位矩阵**：一眼看懂请求排队、计费运行、免费休眠与超期回收全链路及实时插槽占用格。
  - **会话身份自动解析**：自动将生硬的协议字符串转化为「群聊 / 私聊 / 群成员」图标与 `QQ · OneBot`、`WebChat`、`Telegram` 等易读渠道标签。
  - **休眠剩余寿命条 & 语义化文件胶囊**：实时计算距离自动销毁的剩余时间进度条（临期高亮预警），清晰区分 `↑ 附件` 与 `↓ 产物`，支持**表格 / 云机卡片双视图**自由切换。
- **安全实例管控**：对单个会话执行**休眠**或**销毁**（销毁弹窗内置字符匹配校验与一键填入核对，免疫中文输入法回车误触；所有 API Key 全程脱敏，打开面板纯读本地记录不产生云端唤醒计费）。

### 多 API Key 并行轮询

- 配置多把 Key 时，按配置顺序轮询分配给**新创建的沙箱**；不同 Key 拥有独立并发锁，单把 Key 网络慢响应不会阻塞其他 Key 新建沙箱。
- 支持在 `e2b_api_keys` 中使用 `e2b_xxx # 主力号`（或 `# 注释行`）语法添加非敏感备注，方便在控制台直观识别哪一个账号处于冷却保护。
- **不要直接删除仍在使用的 Key**：仍有活跃或休眠沙箱绑定的 Key 若被移除，对应沙箱将无法操作；退役旧 Key 前请先在面板销毁其绑定的沙箱。

<details>
<summary>展开查看：多 Key 容错、持久化与重载保护细节</summary>

- **错误切换与防重开**：创建沙箱遇到 `401 / 402 / 403 / 429` 时暂时冷却该 Key（`429` 冷却 60 秒，其余 300 秒）并自动切换下一把；创建超时、网络中断或 `5xx` 不会盲目跨账号重开，而是保留 `request_id` 尝试找回。
- **状态文件与卸载保护**：沙箱绑定记录保存在 `data/plugin_data/astrbot_plugin_e2b_sandbox/sandbox_sessions.json`（仅存 SHA-256 指纹，不含明文 Key）。新建或恢复前先原子写盘成功再请求云端；状态文件损坏时停止加载并保留原文件；插件重载或卸载会等待进行中的会话锁操作收尾并安全暂停运行中沙箱。

</details>

## 🔧 进阶使用与升级迁移

### 自定义模板（Template）

1. **常规用途直接留空（推荐）**：读写 Excel、画图、网页抓取等任务，`default_template` 留空即可满足需求。
2. **自建专属模板**：通过 E2B 官方工具制作包含特殊依赖的模板后，将模板 ID 填入 `default_template`；建议顺便预装 `fonts-noto-cjk` 字体包，省去首次画图下载字体的等待。
3. **更换模板需重建沙箱**：沙箱在创建时绑定模板；切换 `default_template` 后，请先发回旧沙箱重要文件并销毁旧沙箱，新会话才会使用新模板。

<details>
<summary>展开查看：从旧版单 Key（v1.3.x 及更早）无损升级指南</summary>

1. **先备份**：备份插件配置及 `data/plugin_data/astrbot_plugin_e2b_sandbox/sandbox_sessions.json`。
2. **保留原字段升级**：升级后保持 `e2b_api_key` 仍填着**原来创建旧沙箱的那把 Key A**，并在 `e2b_api_keys` 列表中按需添加新 Key B、C（不要先清空 `e2b_api_key`）。
3. **保存并重载**：插件加载时会自动把旧会话归属绑定到 Key A（与列表重复的 Key 自动去重）。
4. **可选清理旧字段**：确认旧会话恢复正常后，即可将 Key A 移入 `e2b_api_keys` 并清空 `e2b_api_key` 重载。

</details>
