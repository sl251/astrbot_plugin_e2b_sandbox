# AstrBot E2B 云沙箱插件 (astrbot_plugin_e2b_sandbox)

![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20Docker-blue)
![License](https://img.shields.io/badge/License-AGPL--3.0-green)
![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

让你的 AstrBot 拥有专属的云端 Python 电脑，发一句话就能让机器人帮你算数据、画图表、处理表格，既安全又不占你自己的机器资源。

---

## 🎯 它能帮你做什么

日常聊天中，只要对机器人说一句话或发个文件，它就能在云端自动写代码并运行，把结果直接发给你：

- 📊 **读表格画图表**：给机器人发送一个 Excel 或 CSV 文件，说一句“帮我画个各月销售额折线图”，它会自动读取表格、配好中文字体、生成图表并把图片发给你，不会出现方块乱码。
- 🧮 **复杂数据计算与清洗**：发送几万行数据或复杂表格，说一句“把年龄大于 30 岁的人筛选出来存成新表格发我”，它算完后把生成的新 Excel 文件发回给你。
- 🌐 **联网抓取与分析**：问它“看看 astrbot.app 首页的标题是什么”，它能在云端直接访问公开网页，抓取内容并提炼总结回答你。
- 🐍 **临时算题与写代码**：遇到复杂数学运算、批量文字转换或逻辑模拟，直接让它写代码验证，它会把运算结果和解释一并回复在聊天里。

---

## 💡 为什么选它

- **💻 小配置的机器也能干重活**：高负载的数据处理和画图全部跑在 E2B 云端服务器上。哪怕你的 AstrBot 部署在只有 1 核 1G 内存的“轻量小服务器”上，也完全不卡顿、不耗本地资源。
- **⚙️ 不用折腾 Docker 和依赖**：无需在自己的服务器上费心配置容器或排查各种复杂的 Python 库冲突。装好插件、填个 Key，机器人立马就能跑代码干活。
- **🛡️ 代码跑在云端不碰你的服务器**：所有代码都在与你的机器隔离的云端沙箱（云电脑）里执行，云端和本机各管各的权限，普通用户画图跑代码也不用给管理员权限。

## 🛠️ 快速开始

不懂编程也能轻松搞定，只需四步：

### 1. 安装依赖
在运行 AstrBot 的环境中执行以下安装命令：
```bash
pip install 'e2b-code-interpreter>=2.3.0,<3.0.0'
```

### 2. 获取 E2B API Key
前往 [E2B 官网控制台](https://e2b.dev/) 注册账号并获取你的 API Key。

> ⚠️ **费用提示**：E2B 是收费的第三方云服务，新用户注册送一次性 100 美元免费额度。想了解大概能跑多久、什么时候会花完，见下面的「用起来要花多少钱」。

### 3. 填写插件配置
在 AstrBot 管理面板中找到本插件的设置页面：
- 将获取到的 API Key 填入 `e2b_api_key`。
- **国内网络配置**：如果你的机器人服务器在国内、无法直接访问海外网络，请务必在 `proxy` 中填写你的代理地址（例如 `http://127.0.0.1:10809`）。
- **⚠️ 避坑提醒（白名单）**：插件默认开启了白名单（`enable_user_whitelist` 为 true）。**如果白名单列表为空，谁都无法使用代码功能！**
  - 如果想**允许所有人使用**：直接将 `enable_user_whitelist` 设为 `false`（关闭）。
  - 如果**只允许特定人用**：保持开启，并在 `user_whitelist` 中填入对应的用户 ID。

### 4. 重载并测试
在面板中重新加载插件。在聊天中新建一段对话，发送：
> “用 Python 帮我算一下 1 到 100 的累加和，并解释过程”

当机器人调用云端执行并算出 5050 时，说明配置已经全部成功！

## ⚙️ 配置项说明

大部分参数已经经过预先调优，保持默认即可。只有 `e2b_api_key`（必填）、`proxy`（国内服务器必填）以及白名单设置需要根据你的实际情况填写。

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `e2b_api_key` | 字符串 | 是 | 空 | E2B API Key |
| `timeout` | 整数 | 否 | 60 | 单次代码执行超时（秒） |
| `max_output_length` | 整数 | 否 | 2000 | 返回给机器人的执行结果文本上限 |
| `proxy` | 字符串 | 否 | 空 | E2B 请求代理地址 |
| `default_template` | 字符串 | 否 | 空 | 默认使用的 E2B 模板 ID |
| `prefer_e2b_for_code` | 布尔值 | 否 | true | 开启后，日常的计算、绘图、处理附件优先交给云端沙箱；明确针对你自己服务器的任务仍按原权限处理 |
| `hide_restricted_local_tools` | 布尔值 | 否 | true | 开启后，普通用户在当前对话里看不到本机命令工具；管理员不受影响 |
| `enable_user_whitelist` | 布尔值 | 否 | true | 是否限制为白名单用户；关闭后所有用户可用 |
| `user_whitelist` | 字符串列表 | 否 | 空 | 允许使用的用户 ID；启用白名单时留空会禁止所有用户 |
| `max_running_sandboxes` | 整数 | 否 | 3 | 同时运行的沙箱数量上限（1–20）；暂停中的沙箱不占名额 |
| `max_queue_size` | 整数 | 否 | 10 | 名额满时最多让多少请求排队（0–100）；0 表示不排队、直接返回繁忙 |
| `queue_wait_timeout` | 整数 | 否 | 15 | 排队等待名额的最长秒数（1–120） |
| `allow_keep_running` | 布尔值 | 否 | false | 开启后才允许机器人保持沙箱运行；空闲自动暂停仍然生效 |
| `idle_pause_seconds` | 整数 | 否 | 30 | 没有任务的沙箱空闲多久后暂停（5–3600 秒） |
| `paused_sandbox_retention_hours` | 整数 | 否 | 12 | 暂停的沙箱保留多久后自动销毁（1–720 小时）；销毁后变量和文件无法恢复 |
| `max_upload_file_size_mb` | 整数 | 否 | 20 | 单个附件上传上限（1–100 MB），同时也限制网页下载和本地附件读取 |
| `max_return_file_size_mb` | 整数 | 否 | 5 | 允许缓存并发送给你的单个结果文件大小上限（MB） |
| `file_retention_hours` | 整数 | 否 | 24 | 本地导出缓存文件保留时长（小时），缓存目录为 `data/plugin_data/astrbot_plugin_e2b_sandbox/exports/` |

## 📌 使用前必读

在使用前，请了解以下几点关于环境与权限的关键规则：

1. **不用为了本插件开启全局 sandbox**：在 AstrBot 管理面板的 **“设置” -> “普通配置” -> “使用电脑能力”** 中，**“运行环境”** 请设置为 `local` 或 `none`。不用为了接入 E2B 把它改成 `sandbox`——AstrBot 自带的沙箱和本插件不是同一套东西。还需要本机能力就选 `local`，并保持“本机执行需要管理员”开启；只用 E2B 时选 `none` 也可以。
2. **国内网络需要配置代理**：E2B 服务器位于海外，如果你在国内运行机器人，必须配置 `proxy`（例如 `http://127.0.0.1:10809`），否则插件无法连接云端。
3. **普通用户能安全使用云端代码，无需管理员权限**：日常的数学计算、处理文件、画图表等需求，插件会优先指引机器人送往云端沙箱执行。普通群友使用这些云端功能时，不需要拥有你服务器的管理员权限。
4. **本机命令依然受严格权限保护**：云端沙箱完全独立于你的服务器。如果用户尝试让机器人执行这台机器上的本机系统命令，依然严格受 AstrBot 原生管理员权限限制，普通用户无法越权操作你的机器。

## ⏳ 沙箱怎么活、怎么死

你可以把“沙箱”理解为云端为你每个聊天会话分配的一台独立“临时云电脑”。在对话中，你在里面算出的变量、生成的文件都会暂时保留，但它也有明确的运行规则：

- **代码跑完自动暂停**：每次代码跑完后，沙箱会默认自动暂停；如果沙箱处于运行状态且连续 30 秒没有新任务（空闲），也会自动暂停。暂停后不再占用同时运行的名额，沙箱里的文件和变量依然保留。暂停后不再计费，这也是本插件省钱的主要方式。
- **什么时候会丢东西（自动销毁）**：沙箱暂停超过 12 小时后（由 `paused_sandbox_retention_hours` 控制），云端会自动彻底销毁这台云电脑。**销毁后，沙箱内的所有临时变量和文件会永久丢失**。如果有需要留存的重要文件，务必在生成后及时让机器人发给你保存到本地。
- **排队等待机制**：插件默认最多允许 3 个沙箱同时运行。名额已满时，后续请求会自动排队（最多排队 10 个请求，最长等待 15 秒），等到有名额时按顺序执行；超过 15 秒还没轮到的请求会收到“繁忙”提示，需要重新发起。暂停的沙箱可以各自保留文件和变量，所以用过的总人数可以多于同时运行的名额。
- **群聊共享边界（重点防坑）**：在同一个群聊中，所有群成员共用同一个云端沙箱！这意味着群成员之间**没有数据隔离**，大家能看到、修改彼此生成的文件和变量，也能暂停或销毁整个群的沙箱。请把群沙箱当成群协作画板，**切勿在群聊沙箱中处理个人私密敏感文件**！
- **文件体积限制**：上传到沙箱的单个文件默认上限为 20MB；机器人生成并发回聊天中的单个文件默认上限为 5MB，超出限制会被安全拦截。
- **白名单和名额是两回事**：关闭白名单只是允许所有人使用，上面的运行名额、排队和自动清理依然生效，不会因为放开白名单就把资源限制一起关掉。

## 💡 进阶：自定义模板（Template）

**什么是模板？** 可以理解为预装了特定软件或 Python 库的云端系统镜像。如果默认环境没有你需要的复杂第三方库，可以通过模板提前装好。

如果你不知道这是什么，记住以下三条原则：
1. **不知道就留空（最推荐）**：如果你平时只是读写 Excel、画图表、爬取网页或做常规计算，配置项里的 `default_template` **直接留空即可**，官方默认环境完全足够使用。
2. **全局固定环境**：如果你熟悉 E2B 并通过其工具制作了预装特殊库的专属模板，将模板 ID 填入 `default_template`，之后创建的沙箱都会默认使用该环境。自建模板建议预装中文字体包 `fonts-noto-cjk`，可以省去第一次画图时下载字体的等待。
3. **更换模板需注意**：同一个沙箱一旦创建就绑定了模板。如果你想切换模板，请先将当前沙箱中的重要文件下载留存，销毁旧沙箱后再用新模板创建。
